---## 6.9 业务规则
### 6.9.1 规则清单
| 规则编号 | 规则名称 | 说明 |
|----------|----------|------| |
| FIN-01 | 收款自动核销 | 收款时自动核销最早应收单据 |
| FIN-02 | 付款自动核销 | 付款时自动核销最早应付单据 |
| FIN-03 | 应收生成 | 销售出库后自动生成应收款 |
| FIN-04 | 应付生成 | 采购入库后自动生成应付款 |
| FIN-05 | 预收预付 | 预收预付不关联单据 |
| FIN-06 | 账龄计算 | 自动计算逾期天数 |
| FIN-07 | 到期提醒 | 到期前N天提醒 |
| FIN-08 | 逾期预警 | 逾期自动预警 |
### 6.9.2 收款核销规则
```
收款核销顺序规则：

    按先进先出原则核销：
    
    客户YYY应收账款：
    - 销售单1：2025-04-01 应收5000 已收0 剩余5000
    - 销售单2：2025-04-10 应收3000 已收0 剩余3000
    
    本次收款8000：
    自动核销顺序：
    1. 核销销售单1：5000
    2. 核销销售单2：3000
    3. 剩余0（预收款0）
```
