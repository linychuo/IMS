## 9.1 权限管理
### 9.1.1 功能说明
| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 角色管理 | P0 | 自定义角色 |
| 用户管理 | P0 | 用户档案管理 |
| 数据权限 | P0 | 按部门、仓库数据范围控制 |
| 操作权限 | P0 | 增删改查权限细分 |
| 审批流程 | P1 | 多级审批配置 |
### 9.1.2 角色定义
| 角色 | 权限范围 |
|------|----------| |
| 超级管理员 | 全部权限 |
| 管理员 | 除系统设置外全部权限 |
| 仓管员 | 库存相关权限 |
| 采购员 | 采购相关权限 |
| 销售员 | 销售相关权限 |
| 财务员 | 财务相关权限 |
| 查看员 | 仅查看权限 |

## 9.2 系统配置
### 9.2.1 单据编号规则
| 规则配置 | 说明 |
|----------|------|
| 采购订单 | CG + 年月日 + 序号（CG20250502001） |
| 销售订单 | XS + 年月日 + 序号（XS20250502001） |
| 采购入库 | CGI + 年月日 + 序号 |
| 销售出库 | XSC + 年月日 + 序号 |
| 收款单 | SK + 年月日 + 序号 |
| 付款单 | FK + 年月日 + 序号 |
### 9.2.2 业务参数配置
```业务参数：

    ┌─────────────────────────────────────────────────────────┐
    │ 参数名称              │ 默认值   │ 说明                  │
    ├─────────────────────────────────────────────────────────┤
    │ 库存预警-最低库存     │   10    │ 低于此数量预警         │
    │ 库存预警-最高库存     │ 1,000   │ 高于此数量预警         │
    │ 临期预警-天数        │   30    │ 有效期低于此天数预警   │
    │ 呆滞预警-天数        │   90    │ 未动天数超过此值预警   │
    │ 库存预占释放-小时    │   24    │ 订单取消后释放预占    │
    │ 退货期限-天数        │   30    │ 出库后退货期限        │
    │ 采购审批阈值         │10,000   │ 超过此金额需审批      │
    │ 销售审批阈值         │10,000   │ 超过此金额需审批      │
    └─────────────────────────────────────────────────────────┘
```

## 9.3 消息通知
### 9.3.1 通知类型
| 通知类型 | 通知方式 | 说明 |
|----------|----------|------|
| 系统通知 | 系统消息 | 站内消息 |
| 低库存预警 | 短信/微信 | 库存预警 |
| 临期预警 | 短信/微信 | 临期商品 |
| 逾期预警 | 短信/微信 | 应收款逾期 |
| 审批提醒 | 系统消息 | 待审批单据 |
| 订单变更 | 系统消息 | 单据状态变更 |
### 9.3.2 通知配置
```通知配置示例：

    通知类型：低库存预警
    触发条件：商品库存 < 安全库存
    通知方式：☑ 系统消息  ☑ 短信  ☑ 微信
    通知对象：仓管员、管理员
    通知时间：立即
    
    通知模板：
    【进销存系统】商品[{商品名称}]库存不足，当前库存{当前库存}，低于安全库存{安全库存}，请及时补货。
```
## 9.4 操作日志
### 9.4.1 记录内容
| 日志类型 | 记录内容 |
|----------|----------|
| 登录日志 | 登录时间、IP、设备 |
| 操作日志 | 操作人、操作内容、操作时间 |
| 数据变更日志 | 变更前值、变更后值 |
| 接口日志 | 请求参数、响应结果 |
### 9.4.2 日志查询
| 查询条件 | 说明 |
|----------|------|
| 操作人 | 按用户筛选 |
| 操作类型 | 按模块筛选 |
| 时间范围 | 按时间筛选 |
| IP地址 | 按IP筛选 |

## 9.6 验收标准
| 序号 | 验收项 | 验收标准 |
|------|--------|----------|
| 1 | 角色管理 | 可新增、编辑、删除角色 |
