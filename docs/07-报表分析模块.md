## 7.5 经营报表
### 7.5.1 功能说明
| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 利润表 | P1 | 收入、成本、利润统计 |
| 费用表 | P2 | 费用分类汇总 |
| 资金表 | P2 | 资金流入流出分析 |
| 经营汇总 | P1 | 主要经营指标汇总 |
### 7.5.2 利润表示例
```利润表：期间：2025年4月

    ┌─────────────────────────────────────────────────────────────────┐
    │  项目             │  本期金额   │  上期金额   │  同比增减  │
    ├─────────────────────────────────────────────────────────────────┤
    │  一、营业收入      │  600,000   │  500,000   │   +20%    │
    │  其中：销售收入   │  600,000   │  500,000   │   +20%    │
    │  减：销售成本   │  450,000   │  380,000   │   +18%    │
    │  二、毛利        │  150,000   │  120,000   │   +25%    │
    │  减：费用      │   50,000   │   40,000   │   +25%    │
    │  三、净利润      │  100,000   │   80,000   │   +25%    │
    └─────────────────────────────────────────────────────────────────┘
```
### 7.5.3 核心指标
| 指标名称 | 计算公式 | 说明 |
|----------|----------|------|
| 毛利率 | (销售收入-销售成本)/销售收入×100% | 盈利能力 |
| 净利率 | 净利润/销售收入×100% | 整体盈利能力 |
| 库存周转率 | 销售成本/平均库存×100% | 库存流动效率 |
| 回款周期 | 平均回款天数 | 运营效率 |
