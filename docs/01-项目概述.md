## 1.1 项目背景

### 1.1.1 市场现状

根据《2024年中国中小企业数字化转型报告》显示：

| 统计数据 | 说明 |
|----------|------|
| **68%** | 商贸与制造企业仍依赖 Excel 或传统进销存系统管理库存 |
| **45%** | 企业因库存数据实时性不足导致滞销品积压超 30% |
| **28%** | 企业因采购、库存、销售数据断层出现订单交付延误 |

### 1.1.2 行业痛点

传统进销存系统存在 **三大核心痛点**：

```
┌─────────────────────────────────────────────────────────────────┐
│                        三大核心痛点                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│    痛点一：数据孤岛                                              │
│    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐   │
│    │ 采购系统 │ ── │ 销售系统 │ ── │ 库存系统 │ ── │ 财务系统 │   │
│    └─────────┘    └─────────┘    └─────────┘    └─────────┘   │
│         ✗              ✗              ✗              ✗         │
│       孤立         孤立          孤立          孤立           │
│                                                                 │
│    痛点二：库存不准                                              │
│    ┌─────────┐    ┌─────────┐    ┌─────────┐                   │
│    │ 人工错误 │ ── │ 批次混乱 │ ── │ 盘点困难 │                   │
│    └─────────┘    └─────────┘    └─────────┘                   │
│                                                                 │
│    痛点三：决策滞后                                              │
│    ┌─────────┐    ┌─────────┐    ┌─────────┐                   │
│    │ 缺乏数据 │ ── │ 依赖经验 │ ── │ 错失机会 │                   │
│    └─────────┘    └─────────┘    └─────────┘                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.1.3 解决方案

打造一款 **面向中小企业的轻量级进销存系统**，实现 **采购、销售、库存、财务一体化管理**。

## 1.2 项目目标

### 1.2.1 核心指标

| 目标 | 指标 | 衡量标准 |
|------|------|----------|
| **数据实时性** | 库存变动响应时间 < 1秒 | 任意操作后库存数据即时更新 |
| **库存准确率** | ≥ 99.5% | 盘点准确数 / 盘点总数 × 100% |
| **采购效率** | 订单处理时间缩短 40% | 对比传统系统处理时间 |
| **上线周期** | ≤ 2周 | MVP 版本开发周期 |

## 1.3 目标用户

### 1.3.1 用户画像

| 用户类型 | 规模 | 场景 | 痛点 |
|----------|------|------|------|
| **中小商贸企业** | 10-100人 | 批发、零售、五金建材 | 多店铺管理困难、数据分散 |
| **个体工商户** | 1-5人 | 小型仓库 / 门店 | 系统复杂、学习成本高 |
| **初创企业** | 5-20人 | 电商团队 | 快速成长、灵活调整需求 |

## 1.4 适用范围

### 1.4.1 企业类型

| 企业类型 | 业务流程 | 说明 |
|----------|----------|------|
| **销售型企业** | 商品采购 → 入库 → 销售 | 商贸批发、零售贸易 |
| **生产型企业** | 原材料采购 → 入库 → 领料加工 → 产品入库 → 销售 | 简单加工制造 |

### 1.4.2 行业适配

| 行业 | 适配说明 | 特殊需求 |
|------|----------|----------|
| 五金建材 | 规格多样、单位复杂 | 多单位换算 |
| 食品饮料 | 批次管理、保质期 | 临期预警 |
| 服装鞋帽 | 颜色尺码多 | SKU 管理 |
| 医药零售 | 批号管理、效期 | 监管要求 |
| 数码电子 | 串号管理 | 一物一码 |

## 1.6 术语表

| 术语 | 英文 | 说明 |
|------|------|------|
| SKU | Stock Keeping Unit | 库存量单位，商品最小存货单位 |
| FIFO | First In First Out | 先进先出，按入库顺序出库 |
| FEFO | First Expire First Out | 先进先出，按失效日期出库 |
| LIFO | Last In First Out | 后进先出 |
| MOQ | Minimum Order Quantity | 最小订购量 |
| MTP | Maximum Stock | 最大库存 |
| ERP | Enterprise Resource Planning | 企业资源计划 |
| WMS | Warehouse Management System | 仓库管理系统 |
| PRD | Product Requirements Document | 产品需求文档 |
