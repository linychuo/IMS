## 3.2 采购订单管理
### 3.2.1 功能说明
| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 创建采购订单 | P0 | 新建采购订单，选择供应商、商品、数量、价格 |
| 编辑采购订单 | P0 | 修改未审核的采购订单 |
| 审核采购订单 | P0 | 审核通过后生效，支持多级审批 |
| 取消采购订单 | P0 | 取消未入库的采购订单，记录原因 |
| 查询采购订单 | P0 | 多条件查询订单列表 |
| 打印采购订单 | P1 | 打印采购订单或导出 PDF |

### 3.2.2 采购订单流程
```工作流：创建 → 待审核 → 已审核 → 待发货 → 部分发货 → 已完成 / 已取消

    ┌─────────┐
    │  新建   │◄──────────────┐
    └────┬────┘               │
         │                   │
         ▼                   │ (编辑)
    ┌─────────┐              │
    │ 待审核  │──────────────┘
    └────┬────┘
         │ (审核通过)
         ▼
    ┌─────────┐
    │ 已审核  │
    └────┬────┘
         │ (发送订单)
         ▼
    ┌─────────┐
    │ 待发货  │
    └────┬────┘
         │ (确认发货)
         ▼
    ┌─────────┐
    │ 部分发货│
    └────┬────┘
         │ (全部入库)
         ▼
    ┌─────────┐
    │ 已完成  │───► [采购入库单]
    └─────────┘

    取消流程：
    ┌─────────┐    ┌─────────┐    ┌─────────┐
    │ 待审核  │───►│ 取消申请 │───►│ 已取消  │
    └─────────┘    └─────────┘    └─────────┘
         ▲
    ┌─────────┐    ┌─────────┐
    │ 部分入库│───►│ 取消申请 │───►│ 已取消  │
    └─────────┘    └─────────┘    └─────────┘
         ▲ (需退货)
```
