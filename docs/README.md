### 模块优先级

| 优先级 | 说明 | 模块 |
|--------|------|------|
| P0 | MVP核心功能，必须实现 | 采购订单/入库、销售订单/出库、库存台账 |
| P1 | 重要功能，第一迭代实现 | 采购退货、销售退货、盘点、调拨 |
| P2 | 增强功能，持续迭代 | 条码管理、批次管理、数据分析 |
