## 一、项目概述

### 1.1 项目背景

根据《2024年中国中小企业数字化转型报告》显示：
- **68%** 的商贸与制造企业仍依赖 Excel 或传统进销存系统管理库存
- **45%** 的企业因库存数据实时性不足导致滞销品积压超 30%
- **28%** 的企业因采购、库存、销售数据断层出现订单交付延误

传统进销存系统存在三大核心痛点：
1. **数据孤岛** - 采购、销售、库存、财务系统割裂
2. **库存不准** - 人工录入错误、批次混乱、盘点困难
3. **决策滞后** - 缺乏数据分析，依赖经验而非数据

### 1.2 项目目标

打造一款**面向中小企业的轻量级进销存系统**，实现：

| 目标 | 指标 |
|------|------|
| 数据实时性 | 库存变动响应时间 < 1秒 |
| 库存准确率 | ≥ 99.5% |
| 采购效率 | 订单处理时间缩短 40% |
| 上线周期 | ≤ 2周 |

### 1.3 目标用户

- **10-100人** 的中小商贸企业（批发、零售、五金建材）
- 个体工商户（小型仓库 / 门店）
- 初创企业（快速成长的电商团队）

### 1.4 适用范围

| 企业类型 | 说明 |
|---------|------|
| 销售型企业 | 商品采购 → 入库 → 销售 |
| 生产型企业 | 原材料采购 → 入库 → 领料加工 → 产品入库 → 销售 |

## 三、核心功能需求

### 3.1 采购管理模块

#### 3.1.1 功能列表

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 采购订单 | P0 | 创建、编辑、审核、取消采购订单 |
| 采购入库 | P0 | 扫码入库，自动关联采购单 |
| 采购退货 | P0 | 向供应商退货，出库处理 |
| 供应商管理 | P0 | 供应商档案、信用评级 |
| 价格协议 | P1 | 采购价目表、阶梯报价 |
| 到货提醒 | P1 | 预期未到货预警 |
| 智能采购建议 | P2 | 基于销量自动生成采购建议 |

#### 3.1.2 采购流程

```
[采购需求] → [询价比价] → [生成订单] → [供应商确认] → [发货] → [入库检验] → [入库上架]
     │                                                       │
     └───────────────── [采购退货] ←──────────────────────────┘
```

#### 3.1.3 业务规则

| 规则 | 说明 |
|------|------|
| 最低采购量 | 支持设置供应商最小订购量 |
| 到货期限 | 超期自动提醒 |
| 价格锁定 | 入库时锁定采购价格，不受调价影响 |
| 发票匹配 | 采购入库后自动生成应付款记录 |

### 3.2 销售管理模块

#### 3.2.1 功能列表

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 销售订单 | P0 | 创建、审核、取消销售订单 |
| 销售出库 | P0 | 扫码出库，自动扣减库存 |
| 销售退货 | P0 | 退货入库，自动退款处理 |
| 客户管理 | P0 | 客户档案、信用额度 |
| 价格策略 | P1 | 客户等级价、促销活动 |
| 订单跟踪 | P1 | 订单状态全流程可视 |
| 全渠道订单 | P2 | 对接电商平台、线下门店 |
| AI智能报价 | P2 | 基于成本和竞品自动报价 |

#### 3.2.2 销售流程

```
[客户下单] → [信用检查] → [库存预占] → [订单确认] → [备货] → [出库] → [完成]
                              │
                              └── [订单取消/退货] ←── [出库取消]
```

#### 3.2.3 业务规则

| 规则 | 说明 |
|------|------|
| 信用控制 | 超信用额度需审批 |
| 价格优先级 | 客户等级价 > 促销价 > 标准价 |
| 库存预占 | 下单时预占库存，释放时限可配置 |
| 发票开具 | 支持分批开票、合并开票 |

#### 3.3.3 业务规则

| 规则 | 说明 |
|------|------|
| 库位绑定 | 商品可指定默认库位 |

### 3.5 报表分析模块

#### 3.5.1 功能列表

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 销售报表 | P0 | 销售额、毛利、客户分析 |
| 采购报表 | P0 | 采购额、供应商分析 |
| 库存报表 | P0 | 库存周转、呆滞分析 |
| 经营报表 | P1 | 利润表、费用分析 |
| 自定义报表 | P1 | 拖拽式报表设计 |
| 仪表盘 | P2 | 经营数据大屏 |
| AI预测 | P2 | 销量预测、采购建议 |

#### 3.5.2 核心指标

| 指标 | 计算公式 | 说明 |
|------|----------|------|
| 库存周转率 | 销售成本 / 平均库存 × 100% | 库存流动效率 |
| 应收账款周转天数 | 应收账款 / 赊销额 × 30 | 回款效率 |
| 毛利率 | (销售收入 - 销售成本) / 销售收入 | 盈利能力 |
| 库存准确率 | 盘点准确数 / 盘点总数 × 100% | 库存准确度 |
| 订单履约率 | 按时完成订单 / 订单总数 × 100% | 交付能力 |
