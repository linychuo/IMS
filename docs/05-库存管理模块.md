## 5.4 出库管理
### 5.4.1 功能说明
| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 销售出库 | P0 | 销售出库，自动关联销售单 |
| 调拨出库 | P1 | 仓库间调拨出库 |
| 采购退货出库 | P0 | 向供应商退货出库 |
| 其他出库 | P0 | 其他原因出库（领料、报损等） |
| 出库确认 | P0 | 确认出库，更新库存 |
| 先进先出 | P1 | 自动推荐最早批次出库 |

### 5.4.2 出库类型
| 出库类型 | 来源单据 | 说明 |
|----------|----------|------|
| 销售出库 | 销售单 | 销售商品出库 |
| 调拨出库 | 调拨单 | 向其他仓库调出 |
| 采购退货出库 | 采购退货单 | 退货给供应商 |
| 盘亏出库 | 盘点单 | 盘点少出出库 |
| 领料出库 | 领料单 | 生产领料出库 |
| 报损出库 | 报损单 | 商品报损出库 |
| 其他出库 | - | 其他原因出库 |

### 5.4.3 先进先出(FIFO)
```
先进先出推荐逻辑：

    库位库存明细：商品A

    ┌────────┬────────┬────────┬────────┬────────┐
    │ 库位   │ 批次   │ 数量   │ 入库日期│ 有效期  │
    ├────────┼────────┼────────┼────────┼────────┤
    │ A-01   │ B001   │ 10    │ 05-01  │ 05-30  │ ◄── 推荐先出
    │ A-02   │ B002   │ 20    │ 05-03  │ 06-01  │
    │ A-03   │ B003   │ 15    │ 05-05  │ 06-05  │
    └────────┴────────┴────────┴────────┴────────┘
    
    出库10个：自动推荐从A-01库位B001批次出库
```

## 5.6 盘点管理
### 5.6.1 功能说明
| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 定期盘点 | P0 | 全库定期盘点计划 |
| 抽盘 | P0 | 随机抽盘部分商品 |
| 盘点任务 | P0 | 创建盘点任务，分配执行人 |
| 盘点执行 | P0 | 扫码盘点，录入实盘数量 |
| 盘点差异 | P0 | 对比系统库存，计算差异 |
| 盘点调整 | P0 | 确认调整，生成盘盈盘亏单 |

### 5.6.2 盘点流程
```
盘点流程：

    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │ 创建盘点 │───►│ 分配任务 │───►│ 执行盘点 │───►│ 提交审核 │
    │   计划   │    │          │    │  扫码    │    │          │
    └──────────┘    └──────────┘    └──────────┘    └────┬─────┘
                                                          │
                                                          ▼
    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │ 差异分析 │◄───│ 生成报表 │◄───│ 确认调整 │◄───│ 主管审核 │
    │          │    │          │    │          │    │          │
    └──────────┘    └──────────┘    └──────────┘    └────┬─────┘
                                                          │
                                 ┌──────────────────────────┘
                                 ▼
                         ┌──────────────┐
                         │  盘点完成   │
                         │ 生成调整单   │
                         └──────────────┘
```

### 5.11.2 移动加权平均成本
```
移动加权平均成本计算：

    公式：平均成本 = (库存金额 + 新入库金额) / (库存数量 + 新入库数量)
    
    示例：
    当前库存：商品A
    - 数量：100
    - 金额：10,000
    - 平均成本：100
    
    新采购入库：
    - 数量：50
    - 采购价：110
    
    计算：
    新库存数量 = 100 + 50 = 150
    新库存金额 = 10,000 + 50×110 = 15,500
    新平均成本 = 15,500 / 150 = 103.33
```
