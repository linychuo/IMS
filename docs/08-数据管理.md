## 8.2 数据关联关系
```
数据关联图：

    ┌─────────┐
    │ 商品表  │◄───────── 商品分类表
    │
    ├─────────┼─────────── 采购价格表（供应商）
    ├─────────┼─────────── 销售价格表（客户）
    ├─────────┼─────────── 库存表 ──── 库位表 ──── 仓库表
    │         │                │
    │         │                └──────── 批次表
    │
    ├─────────┼─────────── 采购订单表 ◄──── 供应商表
    ├─────────┼─────────── 销售订单表 ◄──── 客户表
    │
    ├─────────┼─────────── 采购入库单
    ├─────────┼─────────── 销售出库单
    │
    └─────────┴───────────── 库存流水表
```

## 8.5 数据备份与恢复
### 8.5.1 备份策略
| 备份类型 | 频率 | 说明 |
|----------|----------|------| |
| 全量备份 | 每日 | 每日凌晨自动全量备份 |
| 增量备份 | 每小时 | 每小时增量备份 |
| 事务备份 | 实时 | 重要操作实时备份 |
| 异地备份 | 每日 | 备份到异地存储 |

### 8.5.2 恢复机制
| 恢复场景 | 说明 |
|----------|------| |
| 全量恢复 | 恢复全量备份 |
| 点时间恢复 | 恢复到指定时间点 |
| 单表恢复 | 恢复指定数据表 |
| 验证恢复 | 恢复后验证数据完整性 |
