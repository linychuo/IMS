## 4.2 销售订单管理
### 4.2.1 功能说明
| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 创建销售订单 | P0 | 新建销售订单，选择客户、商品、价格 | |
| 信用检查 | P0 | 下单前检查客户信用额度 | |
| 库存预占 | P0 | 确认订单时预占库存 | |
| 审核销售订单 | P0 | 审核后生效，触发备货 | |
| 取消销售订单 | P0 | 取消未出库的订单，释放预占库存 | |
| 部分发货 | P0 | 支持分批多次出库 | |
| 查询销售订单 | P0 | 多条件查询订单 | |
| 打印销售订单 | P1 | 打印订单或导出PDF | |
| 订单跟踪 | P1 | 订单状态全流程可视化 | |

### 4.2.2 订单状态流转
```
工作流：创建 → 待审核 → 已审核 → 待备货 → 部分出库 → 已完成 / 已取消

    ┌─────────┐
    │  新建   │◄──────────────┐
    └────┬────┘               │ (编辑)
         │
         ▼                   │
    ┌─────────┐              │
    │ 待审核  │──────────────┘
    └────┬────┘
         │ (审核通过)
         ▼
    ┌─────────┐
    │ 已审核  │──────────────┐
    └────┬────┘              │
         │ (库存预占成功)      │ (库存预占失败)
         ▼                   ▼
    ┌─────────┐        ┌─────────┐
    │ 待备货  │        │ 订单异常 │
    └────┬────┘        └─────────┘
         │ (开始备货)
         ▼
    ┌─────────┐
    │ 备货中  │
    └────┬────┘
         │ (提交出库)
         ▼
    ┌─────────┐
    │ 部分出库│
    └────┬────┘
         │ (全部出库)
         ▼
    ┌─────────┐
    │ 已完成  │───► [销售出库单]
    └─────────┘

    取消流程：
    ┌─────────┐    ┌─────────┐    ┌─────────┐
    │ 已审核  │───►│ 取消申请 │───►│ 已取消  │───►释放预占库存
    └─────────┘    └─────────┘    └─────────┘
         ▲
    ┌─────────┐    ┌─────────┐
    │ 部分出库│───►│ 取消申请 │───►│ 已取消  │───►出库取消处理
    └─────────┘    └─────────┘    └─────────┘
```

## 4.6 价格策略管理
### 4.6.1 功能说明
| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 标准售价 | P0 | 商品标准销售价格 |
| 客户等级价 | P1 | 不同客户等级不同价格 |
| 促销活动 | P1 | 限时折扣、满减活动 |
| 批量报价 | P1 | 按客户批量设置价格 |
| 价格优先级 | P1 | 优先级：客户等级价 > 促销价 > 标准价 |

### 4.6.2 价格策略示例
```
价格优先级示例：

    客户：VIP客户
```
